# Clean Home launcher
1. Create a free GitHub account, make a new repository, upload everything in this folder (keep the .github folder).
2. Open the Actions tab -> "Build APK" -> wait ~3 minutes (or press Run workflow).
3. Open the finished run -> Artifacts -> download CleanHome-apk.zip -> unzip -> app-debug.apk.
4. Copy app-debug.apk to a USB stick, plug into the TV, install with a file manager (allow "unknown sources" when asked).
5. Press Home and choose Clean Home. Dock apps / column count: app/src/main/res/values/config.xml.
